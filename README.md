# Hotel Brisa Urbana — Diagnóstico organizacional

Landing page estática y responsive del proyecto integrador del Hotel Brisa Urbana, C. A.

## Tecnologías
- HTML5
- CSS3
- JavaScript nativo
- SVG integrado para iconografía
- Gráficos CSS sin librerías de terceros

## Abrir localmente
Descarga o clona el repositorio y abre `index.html` en un navegador moderno. No requiere instalación, servidor, compilación ni dependencias.

## Publicar en GitHub Pages
1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment → Source**, selecciona **GitHub Actions**.
3. Guarda el cambio. El workflow `.github/workflows/deploy.yml` publicará automáticamente el sitio cuando se actualice la rama `main`.
4. Revisa **Actions** para conocer el estado de la publicación. Cuando termine correctamente, GitHub mostrará la URL pública en el entorno `github-pages`.

URL de proyecto esperada: https://fenixprojectteam-lgtm.github.io/Hotel-Brisa-Urbana/

## Contenido y límites académicos
- El Hotel Brisa Urbana, C. A. es un escenario ficticio.
- Los 40 registros y los resultados del cuestionario son datos sintéticos elaborados para demostrar el procedimiento de análisis.
- El instrumento contiene 28 ítems de clima y cultura en siete dimensiones; Q29 es un indicador separado de intención de permanencia.
- La lista de verificación agrupa 25 criterios únicos en 122 registros aplicables por área. Sus campos de resultado y evidencia están vacíos: no se realizaron inspecciones.
- Las fotografías son ilustrativas y no representan instalaciones ni trabajadores reales.

## Imágenes
Las fotografías se cargan desde URLs públicas de Unsplash; el navegador requiere conexión a Internet para mostrarlas. El diseño, la navegación y las interacciones principales están implementados localmente en `index.html`.
